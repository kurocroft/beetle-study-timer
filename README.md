Instructions:

You will need Node.js installed on your device before developing.

Type: npm ci
into the terminal to install all dependency versions from the lockfile. This will create your node_modules file.

To run the app,
Type: npm run start
into the terminal to start the app.



Context:

I made this as a simple introduction to myself on using ElectronJS.
I wanted to try making a functional app within my computer that I could use and benefit from.
I also wanted to make an attempt at gamifying my study time with something I would love, which birthed the gimmick between studying & searching for bugs.
